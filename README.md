# Sistema Reciclaje
## Nombre
Sistema de reciclaje de materiales para TESCI.
## Descripción
Es un sistema CRUD (Create, Read, Update, Delete) de reciclaje de materiales desarrollado con PostgreSQL y Java puro en NetBeans IDE, diseñado para el reciclaje de materiales como cartón, plásticos, útiles, ropa o materiales extraviados.
## Uso
Su uso está pensado y diseñado especialmente para la comunidad del TESCI (Tecnológico de Estudios Superiores de Cuautitlán Izcalli), con materiales que son muy comunes de encontrar en dicha institución.
